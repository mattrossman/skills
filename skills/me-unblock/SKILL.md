name: me-unblock
description: Get a stalled task or conversation moving by identifying the obstacle and taking or preparing one concrete next action. Use when the user is stuck, spinning their wheels, or unsure what to do next.
---

# Unblock

Help the user make progress on the task already in front of them. Start from the conversation and available evidence. Identify the desired outcome and the specific uncertainty or dependency stopping progress. Say plainly if the agent's own indecision or repeated suggestions caused the stall.

Do the useful, authorized work you can do now. Check relevant sources when a focused lookup could resolve the obstacle. Stop searching when more research is unlikely to change the next action. Do not ask the user to investigate something you can reasonably check yourself.

Choose one immediate action that advances the outcome. State who does it, where, and what to do. Make it small enough to start now, but meaningful enough to change the situation. Give a recommendation when the evidence supports one and distinguish it from an established fact. Mention another option only if it changes the decision.

If another person must answer or act, identify the right person or channel and the exact decision or information needed. Read the current thread or issue before proposing a reply. Draft the complete message in the user's voice, with the destination and relevant links, so they can send it or review it for approval. Do not send it without the required authorization.

If the user must make a decision, give the decision and a recommendation with the decisive reason. Ask only for missing information that changes the next action. If waiting on an external process, say what is being watched, the next meaningful event, and an evidence-based ETA when available. Keep monitoring when asked to do so.

Lead with one bold, concrete next action or the result of work already done. The first sentence should say what the user can do now without reading the rest. Follow with the shortest explanation that establishes why, plus a link to the relevant evidence or destination. Include the complete draft when a message is the action.

Do not pad the answer with a status recap, a list of adjacent tasks, or speculative follow-ups. If there are multiple possible actions, prioritize the one that moves the requested task forward. If there is genuinely nothing useful to do now, say who or what the user is waiting for and when to check back if the evidence supports a time. Mention an uncertainty only when it changes the action.
