## Prepare

1. Review all local changes and run appropriate checks.
2. Propose the fewest coherent commits, with a message and a brief description of what changes in each, plus the push destination.
3. Report verification results and any work excluded or needing attention.
4. Ask for approval to commit and push together unless the user requested commit-only work. Pause before staging, committing or pushing.

## After approval

- Recheck the work and push target. If either changed materially, revise the plan and ask again.
- Commit only approved work, preserving other changes and staging.
- Approval of the combined proposal authorizes committing and pushing. Honor any narrower approval, then report what was committed, pushed and left over.
