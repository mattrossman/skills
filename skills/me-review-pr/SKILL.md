## Workflow

1. Read the current diff, reviews, and all review threads with replies and resolution state.
2. Review the code using applicable review guidance. Check unresolved feedback against the current head, even when its lines are marked outdated.
3. Refresh the head and review state before reporting. Include remaining feedback with thread links, distinguishing unaddressed issues from changes already made. Base the verdict on the substance, not whether conversations are marked resolved.
