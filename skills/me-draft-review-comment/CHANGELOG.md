# Changelog

## 2026-10-29

### Ground review comments in practical impact

Compare the change with its base and trace a realistic scenario before drafting. A finding is more useful when the author can see how a user would encounter it, and pre-existing issues can be handled separately.

### Vary comment openings

Let the finding determine whether to lead with the problem, its impact or the request. Repeated question-style openings can make comments feel formulaic.
