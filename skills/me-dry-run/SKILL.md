## Scope

Use read-only tools to investigate the request, but do not write, edit, post, create or send anything. Describe any action that would change state instead.

## Workflow

A dry run shows what the agent can do with its current skills, instructions and tools. Use it as a baseline for deciding what to improve.

Handle the request as you normally would up to the first change. Read the relevant sources and show a few real examples of what you found. Report what you actually checked, not an ideal workflow.

Keep the reply short, around 10 lines:

- **Approach:** The steps and tools you would use.
- **Sources read:** What you opened, with a brief example from each.
- **Gaps:** What remains uncertain and what you would ask.
